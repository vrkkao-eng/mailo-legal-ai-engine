# Offline synthetic example

Run `mailo demo --output artifacts/demo` after installing the package.

The input files are shipped as package resources so this works outside the repository:
- `mailo_cli/resources/findings.json`: fictional finding and example.org source.
- `mailo_cli/resources/system.json`: fictional system description.
- `mailo_cli/resources/demo-shapes.ttl`: a synthetic true/false review constraint.

These demonstrate engineering behavior, not substantive MAILO rules or a real clinical system.
